## 🛠 技术栈

- 纯静态 HTML + CSS + JavaScript（无后端依赖）

- GitHub Pages 托管

## 📁 文件结构

```
docs/
├── index.html   # 主页（报价精灵 + 报关助手）
├── 404.html     # SPA 路由回退
└── CNAME        # 自定义域名
```

## 🚀 快速部署到 GitHub Pages

1. Fork 或创建仓库
2. 把 `docs/` 目录推送到 GitHub
3. Settings → Pages → Source 选 `docs/` 目录
4. 绑定自定义域名 `jtour.ai`
