📋 部署方案说明
GitHub Pages 是免费的静态网站托管服务。我们把前端代码放在 docs/ 目录，GitHub 自动将其发布为网站。
项目说明状态

1
创建 GitHub 账号 & 仓库
如果你还没有 GitHub 账号，先注册：github.com/signup

创建新仓库：

  1. 登录 GitHub → 点击右上角 + → New repository
  2. Repository name 填写：jtour-ai（或任意名称）
  3. 设为 Public（GitHub Pages 免费版需要公开仓库）
  4. 勾选 Add a README file
  5. 点击 Create repository
💡 仓库名建议用 jtour-ai，以后 GitHub Pages 默认域名是 yourname.github.io/jtour-ai
2
安装 Git 并上传代码
在你的电脑上，打开 PowerShell 或 CMD，执行以下命令：

① 安装 Git（如已安装可跳过）

下载地址：git-scm.com

② 初始化并推送代码

把下面命令中的 YOUR_GITHUB_USERNAME 替换成你的 GitHub 用户名：

cd C:\Users\49563\Documents\geek2ai

# 初始化 Git 仓库
git init
git add docs/
git commit -m "feat: Jtour Logistics AI Platform v2.0"

# 连接远程仓库（替换用户名）
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/jtour-ai.git
git branch -M main
git push -u origin main
💡 推送时 GitHub 会要求登录，输入你的 GitHub 用户名和密码（或 Personal Access Token）
⚠️ 如果提示 Token 认证，去 GitHub → Settings → Developer settings → Personal access tokens → 创建一个新 Token，勾选 repo 权限
3
开启 GitHub Pages
  1. 进入你的仓库页面：github.com/YOUR_USERNAME/jtour-ai
  2. 点击上方 Settings 标签
  3. 左侧菜单找到 Pages
  4. Build and deployment → Source 选择 Deploy from a branch
  5. Branch 选 main，目录选 /docs
  6. 点击 Save
✅ 保存后等待 1-3 分钟，GitHub 会自动构建并发布网站
💡 Pages 页面会显示 Your site is live at https://yourname.github.io/jtour-ai
4
绑定自定义域名 jtour.ai
CNAME 文件已经写好了（内容是 jtour.ai），只需在阿里云国际站添加 DNS 记录。

① 在 GitHub Pages 设置中填写域名

  1. Settings → Pages → Custom domain
  2. 填入 jtour.ai 并点击 Save

② 在阿里云国际站添加 DNS 记录

登录 阿里云国际站 → DNS 解析 → jtour.ai → 添加记录

记录类型主机记录记录值说明
CNAME@YOUR_USERNAME.github.io根域名 → GitHub Pages
CNAMEwwwYOUR_USERNAME.github.iowww → GitHub Pages
⚠️ 把 YOUR_USERNAME 替换成你的 GitHub 用户名，例如 henry-jtour.github.io
💡 DNS 生效需要 10 分钟~1 小时，生效后 HTTPS 会自动申请
5
配置 AI API Key 并开始使用
网站部署完成后，首次访问会弹出 API Key 配置框。
  1. 访问 jtour.ai（或 GitHub Pages 临时域名）
  2. 弹出配置框 → 选择 AI 服务（推荐 DeepSeek，国内快且便宜）
  3. 注册 DeepSeek 账号：platform.deepseek.com → 创建 API Key
  4. 填入 API Key → 点击"保存并开始使用"
🎉 配置完成！报价精灵和报关助手立刻可用，密钥保存在您的浏览器本地
